# Study 001 — Memory Field

## Observation

Natural systems act within environments shaped by previous inhabitants. Trails,
resource shadows, scars, waste, and dormant structures allow the past to influence
organisms that cannot observe it directly.

## Initial hypothesis

Agents following a resource gradient while depositing a slowly decaying inhibitory
field may preserve escape routes, divide territory, or oscillate between exploration
and avoidance. The first implementation should be minimal enough to understand.

## First questions

- When does memory stabilize a territory instead of freezing it?
- Can differing memory timescales produce apparent species roles?
- Does inherited sensitivity create recognizable lineages?
- Which behavior is measurable, and which is only our interpretation?
