# Behavior Lab — Scar Tissue

A cheap, instrument-first study of path memory. Agents deposit oriented traces. Weak traces attract or align later motion; saturated traces repel it. Idle traces decay, making abandoned territory available again.

The study asks whether reinforcement, congestion, abandonment, and regrowth can emerge from one local memory mechanism. It deliberately excludes specimen materials, depth of field, and cinematic framing.

Initial mutations:

1. saturation changes attraction into repulsion;
2. directional scars encourage alignment along a stored path; crossing resistance is
   still a hypothesis requiring a dedicated metric;
3. refractory scars heal only after sustained inactivity.

Promotion gate: the mechanism must remain interesting and legible in a sharp diagnostic view.
